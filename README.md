# WebRTC Video Streaming Server

Node.js сервер с поддержкой WebRTC для стриминга видео файлов. Сервер выступает в роли ICE-сервера и одного из пиров в WebRTC соединении.

## Возможности

- ✅ WebRTC сервер на Node.js с поддержкой ESM
- ✅ ICE сервер функциональность
- ✅ Стриминг видео файлов из локальной директории
- ✅ HTTP коммуникация между пирами (signaling через HTTP)
- ✅ Современный веб-интерфейс для просмотра видео
- ✅ Polling для получения signaling данных

## Требования

- Node.js 18+ (с поддержкой ESM)
- FFmpeg устанавливается автоматически через npm зависимость `@ffmpeg-installer/ffmpeg` (не требует системной установки)

## Установка

1. Установите зависимости:

```bash
npm install
```

2. Поместите видео файлы в директорию `videos/`:

   - Поддерживаемые форматы: MP4, WebM, OGG, MOV
   - Рекомендуемое разрешение: 640x480 или выше
   - Рекомендуемый FPS: 30

3. Запустите сервер:

```bash
npm start
```

Или в режиме разработки с автоперезагрузкой:

```bash
npm run dev
```

4. Откройте браузер и перейдите по адресу:

```
http://localhost:3000
```

## Использование

1. **Запустите сервер** - сервер будет доступен на `http://localhost:3000`

2. **Откройте веб-интерфейс** - в браузере откроется страница с интерфейсом

3. **Выберите видео** - в правой панели выберите видео файл из списка

4. **Подключитесь** - нажмите кнопку "Подключиться" для установления WebRTC соединения

5. **Просматривайте видео** - после подключения видео начнет стримиться через WebRTC

## API Endpoints

### GET /api/videos

Возвращает список доступных видео файлов.

**Ответ:**

```json
[
  {
    "name": "video.mp4",
    "path": "/videos/video.mp4",
    "size": 1048576
  }
]
```

### GET /videos/:filename

Прямой доступ к видео файлу для загрузки.

### POST /api/offer

Отправка SDP offer от клиента для установления WebRTC соединения.

**Тело запроса:**

```json
{
  "offer": { ... },
  "connectionId": "optional-id",
  "videoFile": "video.mp4"
}
```

**Ответ:**

```json
{
  "connectionId": "connection-id",
  "answer": { ... }
}
```

### GET /api/connection/:id/ice-candidates

Получение ICE кандидатов от сервера (polling).

**Ответ:**

```json
{
  "candidates": [ ... ],
  "hasMore": false
}
```

### POST /api/connection/:id/ice-candidate

Отправка ICE кандидата от клиента.

**Тело запроса:**

```json
{
  "candidate": { ... }
}
```

### POST /api/connection/:id/video

Запрос на стриминг конкретного видео файла.

**Тело запроса:**

```json
{
  "videoFile": "video.mp4"
}
```

### DELETE /api/connection/:id

Закрытие WebRTC соединения.

## HTTP Signaling

Сервер использует HTTP для обмена signaling сообщениями:

- Клиент отправляет `offer` через POST `/api/offer`
- Сервер возвращает `answer` в ответе
- Клиент опрашивает сервер через GET `/api/connection/:id/ice-candidates` для получения ICE кандидатов
- Клиент отправляет свои ICE кандидаты через POST `/api/connection/:id/ice-candidate`
- Используется polling (опрос каждые 500ms) для получения данных от сервера

## Технические детали

### WebRTC Implementation

Сервер использует библиотеку `wrtc` для реализации WebRTC в Node.js:

- RTCPeerConnection для установления соединения
- RTCVideoSource для создания видеотреков из файлов
- FFmpeg для декодирования видео в raw формат

### Видео обработка

Видео файлы декодируются с помощью FFmpeg:

- Формат: YUV420p
- Разрешение: 640x480 (можно настроить)
- FPS: 30
- Конвертация в RGBA для передачи через WebRTC

## Ограничения

- Видео декодируется в реальном времени, что может требовать ресурсов
- Рекомендуется использовать видео файлы с разрешением не выше 1080p
- FFmpeg бинарник устанавливается автоматически через npm (не требует системной установки)
